GNULTE Studio

Faithful terminal re-enactments of every tool in the suite — the boot banner, the real checks, the live screens — typed out in your browser. No install, no root.

How to read these. Every terminal below is a scripted re-enactment built from the real binaries’ banners and screens (v13.5). Values and hostnames are illustrative. Press Play on each one — they also start automatically — and 4× to zip through.

gnulte

the core tester
sudo gnulte -t 192.168.99.13 · root@lanhost 

        

        

          Run it locally:
          sudo gnulte -t 192.168.1.50 -l 300 -j 30
          Full page →
        

        
The boot arc you’ll really see: live privilege/utility checks, then a guided menu from target to conditions. --duration auto-stops any test.

Each host is a fixed three-line row — traffic + ping + grade, then identity, then jitter·loss·avg — so the frame never shifts. g hands you the ready-made gnulte -t <ip> command for an alarming host.

A parallel sweep, then a colour-coded table: vendor, type, ports and name. No root for pings and names — --deep adds ports, banners and an OS guess.
