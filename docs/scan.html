gnulte-scan

The companion scanner — branded SCANLTE on the terminal. Root optional.

▶ Watch a re-enactment in Studio

Discovery

Know what's on your network

GNULTE needs root to shape traffic. Discovering your network mostly does not — and when you do run it as root, it sweeps by ARP too, so hosts that block ping still show up.

Full fingerprint

IP, MAC, OUI vendor and device type — routers, phones, TVs, printers, cameras and IoT. Deep scans also guess the OS from TTL, service banners and port signals.

Interactive table

gnulte-scan -T opens a full-screen, colour-coded device browser with instant filtering, column sorting and a per-device detail pane — organised into Devices / Log / Summary windows (Tab or 1/2/3), with o opening the GNULTE settings page from inside the scanner.

Smart naming

Reverse DNS and mDNS .local lookups plus NetBIOS names, time-bounded so a network without a reverse zone never stalls the scan.

Export anywhere

JSON, YAML or CSV — ready for scripts, dashboards and documentation.

Deep scan

More than a ping

Add --deep for an in-Go port scan of every active device: per-port services and banners on top of the ARP-level inventory, feeding the device-type classifier and an OS fingerprint.

  • Parallel subnet sweep, then a deep in-Go port scan with --deep
  • ARP sweep (--arp) automatic under root — hosts that filter ping still answer ARP
  • Open ports, services and banners feeding device-type and OS detection
  • OS guessed from TTL, banners (OpenSSH, dropbear, IIS, Samba…) and port signals (SMB, RDP, VNC, SSH)
  • Full-screen device browser with -T: Devices / Log / Summary windows (1/2/3), / opens the filter (type to focus, Esc clears), v filters by vendor, s sort, Enter/Space for details, o for settings
  • Live re-scan with --watch N — re-discovers every N seconds and prints exactly what moved: ▲ new, ▼ gone, ~ changed. The -T browser runs the same cadence and marks each row
  • Add --json for a machine feed — one JSON object per sweep on stdout ({"kind":"baseline"}, then {"kind":"delta"}), narrative to stderr, so gnulte-scan --watch 5 --json | jq is a working motion sensor. Refused with -q/--yaml/--csv
  • Inside -T, r re-scans on demand and the status line grows a ▲ new ▼ gone ~ changed legend
  • Summary window cross-references the shared device store — which devices the last LAN watch already knew
  • Vendor from an embedded OUI registry, plus your own override file
  • JSON / YAML / CSV export and a standalone HTML report filed into ~/GNULTE Reports

Usage

Three commands

# table view, details on each device $ gnulte-scan --deep # interactive full-screen browser (Devices / Log / Summary windows) $ gnulte-scan --interactive # custom interface and subnet, JSON export $ gnulte-scan -i wlan0 -C 192.168.0.0/24 -j > devices.json # live re-scan every 5s — shows ▲ new / ▼ gone / ~ changed until Ctrl+C $ gnulte-scan --watch 5

No root needed for pings, names and the embedded OUI database — root unlocks the ARP sweep and the settings page.
