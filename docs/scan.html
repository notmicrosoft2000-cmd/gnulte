gnulte-scan

The companion scanner. No root required.

Discovery

Know what's on your network

GNULTE needs root to shape traffic. Discovering your network does not.

Full fingerprint

IP, MAC, OUI vendor and device type — routers, phones, TVs, printers, cameras and IoT.

Five name sources

mDNS/Bonjour, reverse DNS, NetBIOS and more — merged into the best label for each device.

Gateway always tagged

Router detection by IP and MAC, so the gateway is recognised even when nothing answers.

Export anywhere

JSON, YAML or CSV — ready for scripts, dashboards and documentation.

Deep scan

More than a ping

Add --deep for a full nmap pass on every active device: open ports and OS fingerprinting on top of the ARP-level inventory.

  • Every active device found and inventoried
  • Open ports and OS guesses with --deep
  • Device type detection from OUI and services
  • Switch-adjacent devices grouped clearly
  • JSON / YAML / CSV export

Usage

Three commands

# table view, details on each device $ gnulte-scan --deep # custom interface and subnet, CSV export $ gnulte-scan -i wlan0 -C 192.168.0.0/24 -c > devices.csv

No root needed when the arp-scan OUI database is present.
