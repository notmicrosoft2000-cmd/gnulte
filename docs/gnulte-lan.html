gnulte-lan

The LAN watch — see who is online, how fast they’re moving, and who is misbehaving. Passive: frames are counted, nothing is shaped or intercepted.

▶ Watch a re-enactment in Studio

The watch

The whole network, live

Run it with no target and it auto-discovers the subnet — your own host and the router are skipped. Each host gets a fixed three-line row: traffic + ping + grade up top, its identity below, and one line of figures. The layout is width-stable, so the frame never “gets big and small” as values change.

Live rates

Down/up speed and packet rate per host, refreshed every second, with a running history — who is saturating the network is visible at a glance.

Health grades

Every host is graded: ✓ stable · ~ jittery (>30 ms or loss >2%) · ✗ loss ≥10% · ⚠ alarm. Defaults, or your own thresholds.

Top talkers

t pivots to conversation view — who is talking to whom, with directional rates, so a noisy host is traced back to its peers.

Alarms

Cross a rate or latency threshold (--alarm-rate, --alarm-latency-ms) and the host is flagged instantly — the launch pad for a real gnulte -t test.

Keys

Drive it from the keyboard

  • ↑ / ↓ — move between hosts (hold to repeat, htop-style)
  • ⏎ — detail pane for the selected host
  • s — sort hosts · t — top talkers · a — alarm-only view
  • g — echo the ready-made gnulte -t <ip> test command
  • o — settings page · h — help · q — quit
  • Per-host ⏎ even shows the exact gnulte -t <ip> recipe to test that device

Usage

Three ways to watch

# watch the whole LAN (auto-discovery) $ gnulte-lan # one host, up close $ gnulte-lan -t 192.168.1.20 # headless watch: 60s, CSV export, rate alarms $ gnulte-lan --duration 60 --export watch.csv --alarm-rate 500

No root needed — the watch is passive. Without a raw socket it still runs, marked ¡ speeds-free, with rates dimmed and health pings intact.

Options

Watching, tuned

FlagWhat it does
-t STRINGHost IP(s) to watch, comma-separated (empty = watch the whole LAN).
-i STRINGNetwork interface (default: auto-detect).
--interval NSeconds between updates (default from settings / 1).
--duration NAuto-stop after N seconds (0 = until Ctrl+C).
--history NRate / ping samples kept per host (settings / 60).
--alarm-rate NAlarm hosts above N kbps.
--alarm-latency-ms NAlarm hosts above N ms average ping.
--export FILEAppend per-tick samples as CSV to FILE.
--no-reportSkip the end-of-session HTML report.
-qQuiet: no banner, plain transcript for logs.
--versionPrint version and exit.

Every session ends with an HTML report (per-tool folder under ~/GNULTE Reports) unless you pass --no-report.
