Quick start

Run it as root

Traffic shaping needs root (ARP spoofing + tc netem); discovery and inventory tools run as a normal user.

# interactive: scan → select → configure → run $ sudo gnulte # one device, voip profile, auto-stop after 5 minutes $ sudo gnulte -t 192.168.1.20 --profile voip --duration 300 # whole subnet throttled, excluding your device $ sudo gnulte -r 192.168.1.0/24 -w 192.168.1.100 --profile throttle --duration 600 # full-screen settings editor (colours, defaults, log mode) $ sudo gnulte --settings # discreet spoofing: answer ARP only when asked (far less noise on the LAN) $ sudo gnulte -t 192.168.1.20 --profile voip --duration 300 --stealth # detect duplicate IPs / ARP conflicts, then exit $ sudo gnulte --dupcheck

Companion tools

The full toolbox

One shared identification engine, five focused binaries. The wiki tool reference covers flags in more depth.

gnulte

The core tester — reroute a target through your machine with ARP spoofing and apply tc netem latency, jitter, loss, duplication, reordering and bandwidth caps. Guided menu, 12 preset profiles, --random live variation, a per-second ping dashboard, and an HTML report with SVG latency timelines. Self-healing spoof monitor, guaranteed cleanup, refuses the gateway and itself.

gnulte-scan

Parallel subnet scan + in-Go port scanner with --deep, OS fingerprinting, and an automatic ARP sweep under root that catches ping-blocking hosts. mDNS .local and NetBIOS names, embedded OUI vendor, device types, colour-coded scan tables, an interactive -T monitor with Devices / Log / Summary windows and an in-scanner settings page (o), HTML reports filed into ~/GNULTE Reports, and JSON / YAML / CSV export.

gnulte-lan

Live LAN watch: discovers the whole subnet (router skipped), then repaints per-host down/up speed, packet rate and latency every second with device identity — MAC, vendor, type, hostname — scaled row blocks with a health grade, one stable colour per IP, and a four-screen console: hosts, ranked talkers (with bars and peers), per-pair flows (root socket) and the live ARP neighbours table. Tracks who talks to whom, raises lightweight alarms when a host crosses a rate or latency threshold, streams per-tick CSV, and files a polished HTML report into ~/GNULTE Reports. Root unlocks byte-accurate flows and net rates.

gnulte-wifi

Wi-Fi audit — crafted 802.11 deauthentication frames from a monitor-mode adapter. Burst size, inter-burst delay, per-frame jitter and reason-code mixing, with channel hopping to keep a roaming AP in range. Authorized testing only.

gnulte-devices

Instant ARP/neighbour inventory — vendors, mDNS names, type guesses, HTML reports. Add -s to sweep the subnet in parallel too.

Operational

Evidence, state and safety

How runs start, what they produce, and what they refuse to do.

Reports

Output lands in gnulte-session-ts.html — SVG latency charts with the full live console log, ready to attach to a ticket or paste into documentation.

Capture & export

--capture evid.pcap stores a packet capture of the whole test. --export CSV writes per-second dashboard data for external analysis.

Safety & state

Versioned safety acceptance persists in ~/.config/gnulte-go/acceptance.json; the documents (SAFETY.md, DISCLAIMER.md, AUTHORIZED-USE.md, NETWORK-TESTING.md, FIRST-RUN-NOTICE.md) live alongside the license in the repository and are bundled at install time. Editor defaults live in ~/.config/gnulte-go/config.json.

Safety rails

Parameter validation estimates impact before applying. The gateway and your own machine are refused as targets, and every run ends in a full cleanup.

Verification

Targets are verified reachable before shaping starts, and the spoof monitor revives dead arpspoof processes mid-test so runs complete.

Settings

sudo gnulte --settings opens a full-screen colour editor with live preview: themes (classic, hacker, ocean, sunset, highcontrast, mono, custom), verbosity (easy, normal, expert) and console log mode. Saved defaults live in ~/.config/gnulte-go/config.json.
