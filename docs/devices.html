gnulte-devices

Your LAN, in one table. No sweeps required.

▶ Watch a re-enactment in Studio

Inventory

What's on your network, right now

gnulte-devices reads the neighbour table (and, as root, directly from the wire) and enriches every entry with the shared identification stack: OUI vendor database, mDNS and reverse-DNS names, and a device-type guess. Run it whenever you need a snapshot.

Instant

Reads the ARP/neighbour table first — every entry is listed before any packet leaves the machine.

Identifies

Embedded ~33 000-prefix OUI registry plus your own overrides. mDNS .local names and reverse DNS per host.

Classifies

Router, phone, TV, printer, camera, Raspberry Pi or plain device — from vendor, hostname and open ports.

Portable output

Colour table, or JSON / YAML / CSV straight to stdout, a file target, or an HTML report per run.

Optional sweep

Deeper, if you want it

By default gnulte-devices is a read-only snapshot. Add -s and it also pings the subnet in parallel, so hosts that are up but briefly absent from the neighbour table are still found.

  • ARP-table inventory, no root and no packet noise
  • Optional -s parallel subnet sweep to catch the rest
  • Shared identification engine with gnulte-scan
  • JSON, YAML, CSV, HTML report, or table to a file
  • -n skips name lookups for a fast headless list

Usage

Everyday commands

# quick snapshot of everything the machine already knows $ gnulte-devices # include hosts only reachable via a live sweep $ gnulte-devices -s # machine-readable, for scripts and dashboards $ gnulte-devices -j > devices.json # full HTML report of the run $ gnulte-devices -H devices.html
