Get GNULTE

Linux. Root for shaping, none for scanning.

Install

Straightforward to set up

# clone the repository $ git clone https://github.com/notmicrosoft2000-cmd/gnulte.git $ cd gnulte # install (also installs dependencies) $ sudo ./installer.sh

What the installer does

  • Installs dependencies via your package manager
  • Installs GNULTE and gnulte-scan to /usr/local/bin
  • Sets up the man page
  • Re-run to check for updates and reinstall
Update
$ cd gnulte $ sudo ./installer.sh --update

Detects whether the remote has new commits and installs them.

Uninstall
$ sudo ./uninstall.sh # --purge also removes config files $ sudo ./uninstall.sh --purge

Packages

Distro packages

Arch / AUR & CachyOS
$ cd packaging/aur && makepkg -si
Debian / Ubuntu
$ cd packaging/deb && dpkg-buildpackage -us -uc

The .deb installs /usr/bin/GNULTE, /usr/bin/gnulte-scan, a man page and docs.
