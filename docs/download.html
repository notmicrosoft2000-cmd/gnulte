Get GNULTE

Linux. A normal user can discover and inventory; root is needed for shaping and injection.

Install

Straightforward to set up

# clone the Go repository $ git clone https://github.com/notmicrosoft2000-cmd/gnulte-go.git $ cd gnulte-go # build and install to /usr/local/bin $ sudo ./install.sh

What the installer does

  • Builds the five binaries: gnulte, gnulte-scan, gnulte-devices, gnulte-traffic, gnulte-wifi
  • Installs them to /usr/local/bin
  • Installs safety documentation under /usr/local/share/doc/gnulte-go/
  • Run sudo ./install.sh again after git pull to update
Update
$ cd gnulte-go $ git pull $ sudo ./install.sh

Pulls latest commits, rebuilds and reinstalls.

Uninstall
$ sudo ./uninstall.sh # --purge also removes config and acceptance records $ sudo ./uninstall.sh --purge

From source

Building without install

Build locally
$ ./build.sh # runs tests and vet, then writes ./gnulte ./gnulte-scan ...

Needs a working Go toolchain; the script uses ~/.local/bin/go if present, or the system Go.

Requirements

Traffic shaping needs root (ARP spoofing + tc netem), iproute2 and an ICMP-capable network. Deep scans, inventory and traffic runs work as a normal user. arp-scan is optional and used opportunistically when available as root.

GNULTE uses ARP spoofing and kernel-level traffic shaping on the gnulte binary. Use it only on networks you own or have written permission to test. Distributed under the GPL-3.0-or-later licence.
