GNULTE

GNU LAN Network Testing Environment

GNULTE is a network processing script.

An interactive testing tool that reroutes a target's traffic through your machine and applies kernel-level shaping with tc netem — so you can measure how devices behave under real latency, jitter, packet loss and bandwidth limits. It scans first, asks permission first, and cleans up after itself.

The toolkit

Scan. Shape. Measure.

Everything GNULTE does, from discovery to a finished report.

Scan

Discovers every device and its vendor, hostname, ports and type.

Shape

Applies conditions on the wire via ARP spoof routing and tc netem.

Monitor

Per-target dashboard, pinged every second while the test runs.

Report

Each run ends with SVG latency graphs and a clean-up.

Capabilities

Built for real networks

A terminal tool that treats testing seriously.

LAN scanning

ARP scan with full device fingerprinting — OUI vendor, hostname, open ports and type. Routers, phones, TVs and IoT, all labelled.

Targeting

One IP, several IPs, a whole subnet, or an IP looked up from a MAC. Whitelist your own devices and range tests skip them automatically.

Traffic shaping

Latency, jitter, loss, duplication, reordering and bandwidth via tc netem, with caps chained so nothing is dropped. --duration auto-stops runs; --random varies conditions live.

Validation

Every parameter is checked before it runs and its impact is estimated out loud. It refuses to target the gateway or your own machine.

Live dashboard

Every target is pinged once per second — last, min, max, average and loss, and the report is an SVG graph of the whole run.

Self-healing

The spoof monitor revives dead arpspoof processes mid-test. Targets are verified reachable first, and cleanup always runs — qdisc removed, forwarding off.
