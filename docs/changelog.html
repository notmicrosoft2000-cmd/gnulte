v13.4

Latest 28 Sep 2026
  • Watch polish — gnulte-lan becomes a smooth, stable monitor you can trust while picking test targets: every host now occupies a fixed three-line block (traffic+latency, identity, session health), so rows neither grow nor shrink between ticks and the frame never jumps around.
  • Pick-a-target grades — each row carries a one-glyph health verdict (✓ stable, ~ jittery or lossy, ✗ flaky, ⚠ alarming) plus jitter, loss and whole-watch average speeds, so a good GNULTE test device is obvious at a glance.
  • Test-recipe button — the detail pane ends with test with: gnulte -t <ip>, and pressing g echoes that exact command under the footer. The watch is explicitly the “choose your target” half of the toolkit now.
  • Header health line — the status bar gains hosts-up count and a self · gateway ←→ RTT line (the gateway is pinged alongside the watch), so “is my uplink fine?” is answered without opening anything.
  • Smooth keyboard — pings run in the background and results land between ticks, so a slow or silent host can never freeze the arrows; holding ↑/↓ scrolls fast just like htop (raw terminals deliver no auto-repeat).
  • Locked columns — rate, latency and health cells are fixed-width everywhere (the alarm badge reserves its own column), and aligned totals replace the old cut-off line.
  • Version 13.4 across all five binaries.

v13.3

28 Sep 2026 · 497cda7
  • Banner & boot polish — gnulte-lan opens with the GNULTE-LAN block wordmark, a purpose line that answers “what is this for?”, and width-aware boot notes (skipped with -q).
  • Arrow keys work — the watch is now a real interactive screen: ↑/↓ move a host cursor, and the live frame redraws instantly between ticks.
  • Host detail pane — ⏎/Tab opens a per-host card: MAC/vendor/type/hostname, down/up with session peaks, latency min/avg/max/loss, three relative sparklines (latency, down, up), and the host's top conversations this interval.
  • Sort, filter, panes — s cycles traffic → latency → address order, a filters to only the alarming hosts, t toggles the global top-talkers pane, and h expands the key hints footer.
  • Options mid-watch — o opens the settings editor live: interval, history depth, timeout, alarm thresholds and beeps apply to the running watch without a restart.
  • Scroll-safe frames — the host window is packed by line budget (not row count), so sparse multi-line rows fit any terminal height, the cursor never leaves the screen, and ▴/▾ indicate hidden hosts.
  • Self-explaining help — --help now leads with gnulte-lan's purpose and ends with examples; the tool's doc comment tells the full story.
  • tui.KeyStream.Poll — new non-blocking key decode in the shared terminal library (arrows, ⏎, Esc, runes) that never drops a queued sequence; used by the interactive watch.
  • Version 13.3 across all five binaries.

v13.2

28 Sep 2026 · 0944a3a
  • GNULTE-LAN — gnulte-traffic is renamed gnulte-lan and grows into a full live LAN watch: per-host down/up speed, packet rate and latency, refreshed every interval.
  • Auto-discovery — with no -t, gnulte-lan sweeps the subnet in seconds and watches every live host, merging ARP-table neighbours so ping-silent devices still appear — while always skipping your own machine and the gateway.
  • Identity layer — each watched host is labelled with MAC, vendor (embedded OUI), device type and hostname from the ARP+neighbour table and mDNS.
  • Top talkers — a passive per-interval flow engine (AF_PACKET, TCP/UDP port parsing) shows which endpoints are exchanging the most bytes and packets, bolded when a watched host is involved.
  • Lightweight alarms — rate (kbps) and latency (ms) thresholds, set in the settings editor or via --alarm-rate/--alarm-latency-ms; one beep per tick and a ⚠ marker on offending hosts. Zero disables.
  • CSV export — --export file.csv appends a row per host per tick (rates, packets, RTT, loss).
  • HTML report — the session report gains per-host cards with rate + latency sparklines, each host's top-5 conversations, and a global top-talkers table.
  • Speeds-free fallback — without root the packet counter degrades gracefully (window warns once) and latency/identity/talkers still run.
  • Version 13.2 across all five binaries.

v13.1

28 Sep 2026 · 89de846
  • Smarter target setup — before gnulte sweeps the whole subnet it now asks whether you'd rather type an IP (or hostname) by hand; one keypress skips the sweep and the device table entirely.
  • Router-safe ranges — -r sweeps and the guided “all devices” pick never target the gateway (shaping the router would cut your own uplink). It stays selectable by number when you really mean it.
  • Device-ID guidance — the device table now points at gnulte-scan (SCANLTE) for deeper identification: vendors, device types, mDNS/DNS-SD services and port scans.
  • Enter = manual — the profile picker is a numbered grid and a bare Enter selects manual configuration, so you never have to type a profile name to skip the presets.
  • Twice the profiles — six new presets join the lineup: satellite, cellular, dialup, congested, bufferbloat and nightmare.
  • Polished session report — the SVG report is renamed gnulte-go-scan-report-<date>-<time>-<count>.html and redone: UP / DEGRADED / UNSTABLE status pills, a sorted target-summary table, and per-target cards with area-filled latency timelines, timeout markers and headline stats, above the full command history.
  • Version 13.1 across all five binaries.

v13.0

27 Sep 2026 · 2642181
  • Stealth ARP spoofing — gnulte -S/--stealth uses a built-in AF_PACKET spoofer that answers only when asked and re-arms target caches on a slow, jittered ~30 s schedule. Far less visible to other scanners on the LAN; drops the arpspoof(8) dependency in stealth mode.
  • Wi-Fi testing that sticks — gnulte-wifi gains per-frame timing jitter (--jitter-ms, defeats reconnect timers), rotating deauth reason codes (--mix), channel-hopping (--hop-channels/--channels), and a second Ctrl+C to force-quit the summary.
  • ARP discovery — gnulte-scan automatically sweeps the subnet when run as root, so hosts that block ping still show up.
  • Tabbed monitor — gnulte-scan -T is now a Devices / Log / Summary window set (Tab or 1/2/3), with o opening the settings page from inside the scanner.
  • Per-target traffic windows — gnulte --traffic-window opens one monitor terminal per target when shaping several devices at once.
  • Settings TUI — a categorized full-screen editor (jog/toggle keys, reset) across the tools; StealthArp preference added.
  • Reports hub — all tools file HTML reports into ~/GNULTE Reports, with an interactive y/N ask on interactive runs; the engine command transcript now prepends the report log.
  • Clean exits — sessions always tear down sessions (defer-based stop), so spoofs and shapers are restored even on nested returns.
  • SCANLTE — gnulte-scan gets the rebrand: ASCII block logo and “side tool for GNULTE” tagline.
  • Avahi-style service discovery — gnulte-scan asks the LAN's mDNS/DNS-SD responders (single two-phase PTR→SRV/A exchange) what each device offers: airplay, chromecast, homekit, matter, ssh, printer, scanner, vnc and more. Advertised services appear in a SERVICES column, the interactive detail pane and filter, JSON/YAML/CSV exports, and the scan summary.
  • Ping history per host — the monitor dashboard and gnulte-lan (then gnulte-traffic) keep a rolling latency window per target, with a block sparkline under each live traffic row (last RTT, average, loss). Depth is configurable (ping history depth, 10–240).
  • Settings that scale — the settings TUI adapts to wider terminals (up to ~96 columns) and regroups every option under dim section headers (Network & Monitor, Scanlte Scan, Traffic Engine, GNULTE-WIFI, Terminal & UI), with g/G first/last keys and header-skipping navigation.
  • Advanced mode — a settings toggle controls whether gnulte echoes the exact command line for every tc/arpspoof/sysctl step as it runs; the HTML report transcript records them either way.
  • Typing animation — on live terminals the interactive confirmation is typed out character by character (instant when piped or quiet).
  • Version 13.0 across all five binaries.
