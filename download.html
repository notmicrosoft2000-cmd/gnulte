From the repo
# install both tools to /usr/local/bin $ sudo install -m755 GNULTE /usr/local/bin/GNULTE $ sudo install -m755 gnulte-scan /usr/local/bin/gnulte-scan
Dependencies
arp-scan for discovery · dsniff for arpspoof · iproute2 for tc netem. Debian/Ubuntu: apt install arp-scan dsniff iproute2. Arch: pacman -S arp-scan dsniff iproute2.
Packages
# Arch / AUR & CachyOS $ cd packaging/aur && makepkg -si # Debian / Ubuntu $ cd packaging/deb && dpkg-buildpackage -us -uc
The Debian build produces a .deb that installs /usr/bin/GNULTE, /usr/bin/gnulte-scan, a man page and documentation. The Arch PKGBUILD builds both binaries plus docs.
GNULTE uses ARP spoofing and kernel-level traffic shaping. Use it only on networks you own or have written permission to test. Distributed under the GPL-3.0-or-later licence.
