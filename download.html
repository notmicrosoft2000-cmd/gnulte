From the repo

$ sudo install -m755 GNULTE /usr/local/bin/GNULTE $ sudo install -m755 gnulte-scan /usr/local/bin/gnulte-scan

Packages

Arch: cd packaging/aur && makepkg -si · Debian/Ubuntu: cd packaging/deb && dpkg-buildpackage -us -uc
