# What GNULTE Does

GNULTE is designed for controlled network testing.

The system can combine:

```
GNULTE-SCAN
    ↓
LAN discovery
    ↓
target identification
    ↓
GNULTE
    ↓
controlled network impairment
    ↓
application/network observation
```

The legality of a specific activity depends on the jurisdiction, the
authorization you have, the specific actions taken, the systems
affected, contractual obligations, and other circumstances. Use GNULTE
only where you are authorized to do so and where the activity is
lawful.

Example authorized test:

```
A developer owns an application server.

The developer wants to know how the application behaves under:

    100 ms latency
    20 ms jitter
    2% packet loss
    reduced bandwidth

GNULTE can be used to reproduce those conditions.
```

This is the intended type of use.
