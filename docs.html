Quick start and reference.

Quick start

Run it as root, pick a target, adjust the conditions and start. Full flag reference lives in GNULTE --help.

# interactive mode: scan → select → configure → run $ sudo GNULTE # one device, voip profile, 5 minutes $ sudo GNULTE -t 192.168.1.20 --profile voip --duration 300 # whole subnet, throttled $ sudo GNULTE -r 192.168.1.0/24 --profile throttle
Parameters
--latencybase delay, ms
--jitterdelay variance, ms
--losspacket drop %
--duplicateduplicate packet %
--reorderout-of-order packet %
--bandwidthcap, kbps
--durationauto-stop seconds
--randomvary during a run
--capturesave a .pcap of the test
Profiles
gamingraised latency
streamingbuffering behaviour
voipcall degradation
webmild, acceptable
extremeworst case
throttlelow bandwidth

Save your own combinations with --save-profile.

Settings

Colour themes, verbosity and console logging are configured with GNULTE --settings and saved to ~/.gnulte.conf.

Themes

classic, hacker, ocean, sunset, highcontrast, mono, custom.

Verbosity

easy, normal or expert — expert confirms every raw command first.

Safety

--stealth hides GNULTE's presence on systems you own.
