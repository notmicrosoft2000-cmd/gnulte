# Security Policy

If you discover a security vulnerability in GNULTE or GNULTE-SCAN,
report it privately to the project maintainers when possible.

Do not publicly disclose a serious vulnerability before maintainers
have had a reasonable opportunity to investigate and address it.

Security reports should include:

* affected component
* affected version
* reproduction steps
* expected behavior
* actual behavior
* security impact
* proposed mitigation, if known

Do not include secrets, credentials, private packet captures, or
unnecessary personal information in the report.
